# Support Guide

## 1. Introduction

Thank you for purchasing the Travel Package Selector template.

This document explains the available support, troubleshooting procedures, update policy and limitations of the product.

## 2. Support Period

- Free technical support is available for 30 days from the date of purchase.
- Support requests are generally answered within 2 business days.
- Response time is a target and may vary depending on the complexity of the issue.
- Support is provided through the seller's designated support contact.

## 3. What Support Covers

Support covers:

- Installation and setup guidance.
- Clarification of included features.
- Troubleshooting reproducible bugs in the original template.
- Guidance on basic customization.
- Clarification of the supplied documentation.

Verified bugs in the original, unmodified template will be addressed without an additional charge.

## 4. What Support Does Not Cover

The following are not included:

- Custom feature development.
- Backend or database development.
- Payment gateway integration.
- Authentication and user management.
- Third-party API integration.
- Hosting and server administration.
- Custom design or branding.
- Extensive debugging of buyer-modified code.
- Ongoing website maintenance.

These services may be arranged separately.

## 5. Updates Policy

- Free product updates are included for 6 months from the purchase date.
- Updates may include bug fixes, compatibility improvements and minor enhancements.
- Major new product editions or separately sold products are not automatically included.
- Updates are provided at the seller's discretion.
- Buyers should back up their customized projects before applying updates.

## 6. Installation and Setup

To install the template:

1. Install a compatible version of Node.js and npm.
2. Open the project directory in a terminal.
3. Run `npm install`.
4. Run `npm run dev` to start the development server.
5. Run `npm run build` to generate a production build.

Refer to `INSTALLATION.md` for detailed instructions.

## 7. Common Troubleshooting

### Images are not displaying

Check the image URL, internet connection and external image service availability.

### Package information is missing

Check `src/data/packages.json` and ensure that package entries follow the expected data structure.

### Saved trips or bookings are missing

The template uses browser localStorage for demonstration purposes. Browser storage may be cleared or restricted.

### Navigation issues

Check the route configuration and ensure that the relevant page components are present.

## 8. Requesting Support

When submitting a support request, include:

- Purchase reference, if applicable.
- A clear description of the issue.
- Steps to reproduce the problem.
- Error messages or screenshots.
- Node.js and npm versions.
- Browser and operating system details.

Never share passwords, API keys, payment details or other sensitive credentials.

## 9. Buyer Responsibilities

Buyers are responsible for:

- Customizing the template for their business.
- Checking the licences of additional assets and dependencies.
- Configuring hosting and deployment.
- Securing any backend services they independently introduce.
- Maintaining backups of customized projects.
- Testing their final website before production use.
